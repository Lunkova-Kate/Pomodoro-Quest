# Помодорный квест

Android-приложение с Pomodoro-таймером и простой RPG-прогрессией. За завершённые фокус-сессии пользователь получает опыт (XP) и повышает уровень. Приложение работает офлайн.

Зачем нужен проект и для кого он создаётся, описано в [VISION.md](VISION.md).

## Объём первой версии (MVP)

В первую версию входят:

- главный экран с текущим уровнем, накопленным XP и прогрессом до следующего уровня;
- выбор длительности фокус-сессии: 15, 25, 45 или 60 минут;
- таймер с паузой, продолжением и отменой сессии;
- начисление XP только за успешно завершённую сессию;
- повышение уровня по мере накопления XP;
- экран результата с длительностью сессии, полученным XP и изменением прогресса;
- локальное сохранение опыта и уровня между запусками приложения.

## Основные пользовательские сценарии

### 1. Начать фокус-сессию

1. Пользователь открывает приложение и видит свой уровень и прогресс.
2. Выбирает длительность сессии или оставляет уже выбранную.
3. Нажимает кнопку запуска.
4. На экране отображаются оставшееся время и ход сессии.

### 2. Поставить таймер на паузу или продолжить

1. Во время сессии пользователь нажимает «Пауза».
2. Отсчёт времени останавливается.
3. После нажатия «Продолжить» отсчёт идёт с оставшегося времени.

### 3. Отменить сессию

1. Пользователь нажимает «Отмена» во время активной или приостановленной сессии.
2. Сессия завершается без награды.
3. Пользователь может начать новую сессию.

### 4. Завершить сессию и получить опыт

1. Таймер доходит до нуля.
2. Сессия считается завершённой, пользователю начисляется XP.
3. Открывается экран результата: длительность, полученный XP, изменение прогресса.
4. Если достигнут порог следующего уровня, уровень повышается, а экран сообщает об этом.
5. Пользователь может вернуться на главный экран.

### 5. Вернуться в приложение позже

1. Пользователь закрывает приложение после завершённой сессии.
2. При следующем запуске накопленный XP и уровень остаются прежними.

## Начисление опыта

Предварительные значения наград:

| Длительность | Награда |
| --- | ---: |
| 15 минут | 50 XP |
| 25 минут | 100 XP |
| 45 минут | 180 XP |
| 60 минут | 250 XP |

XP начисляется один раз за завершённую сессию. Пауза сама по себе не лишает награды, отменённая сессия награды не приносит.

**До реализации нужно определить:** сколько XP требуется для каждого следующего уровня и как показывать остаток опыта до него. Конкретная формула уровней пока не утверждена.

## Критерии готовности MVP

Первая версия готова, когда выполняются все условия:

- [ ] Приложение запускается на Android без подключения к интернету.
- [ ] На главном экране отображаются уровень, XP и прогресс до следующего уровня.
- [ ] Можно выбрать одну из четырёх длительностей и запустить таймер.
- [ ] Таймер показывает оставшееся время и завершается по достижении нуля.
- [ ] Пауза останавливает отсчёт, а продолжение возобновляет его с того же места.
- [ ] Отмена прекращает сессию и не начисляет XP.
- [ ] Успешно завершённая сессия начисляет XP ровно один раз согласно выбранной длительности.
- [ ] При достижении порога XP уровень повышается, а прогресс до следующего уровня пересчитывается.
- [ ] После завершения сессии показывается экран результата.
- [ ] После закрытия и повторного открытия приложения опыт и уровень сохраняются.

## Что не входит в первую версию

Достижения, настройка персонажа, дополнительные RPG-механики, аккаунты, синхронизация между устройствами и онлайн-функции. Отдельный таймер отдыха тоже пока не входит в MVP: после завершения сессии пользователь возвращается на главный экран.
