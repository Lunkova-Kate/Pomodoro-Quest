# Помодорный квест
## 1. Идея
**Помодорный квест** - Android-приложение для концентрации, объединяющее технику Pomodoro с простыми RPG-механиками.
Пользователь запускает таймер, работает над своей задачей и после завершения фокус-сессии получает опыт (XP). Накопленный опыт позволяет повышать уровень в приложении.
Идея проекта заключается в том, чтобы сделать регулярную работу над задачами немного интереснее. Вместо обычного отсчёта времени пользователь получает дополнительную мотивацию в виде игрового прогресса.

## 2. Проблема
Pomodoro-таймеры помогают организовать рабочее время, но сами по себе не всегда мотивируют пользоваться ими регулярно.
После завершения сессии пользователь видит, сколько времени он потратил на работу, но часто на этом всё заканчивается. Результаты предыдущих сессий могут сохраняться в статистике, однако она не всегда даёт ощущение развития.
**Помодорный квест** предлагает дополнить привычный таймер системой опыта и уровней. Каждая завершённая сессия будет влиять на общий прогресс, который пользователь сможет видеть при следующем запуске приложения.
Предполагается, что такая система поможет поддерживать интерес к регулярным фокус-сессиям.

## 3. Целевая аудитория
Приложение рассчитано на студентов, начинающих специалистов и всех, кому бывает сложно сосредоточиться на задачах.
В первую очередь оно может быть интересно людям, которым нравятся игры с прокачкой персонажа, накоплением опыта и повышением уровней.
При этом для использования приложения не нужно разбираться в RPG. Игровая система будет достаточно простой, чтобы не отвлекать от основной задачи - концентрации.

## 4. Ценность 
Помодорный квест даёт пользователю возможность отслеживать не только время, проведённое за задачами, но и свой прогресс внутри приложения.
Даже короткая завершённая сессия приносит опыт и приближает к следующему уровню. Даже небольшие ежедневные усилия постепенно складываются в заметный результат.
Игровая система не заменяет реальную пользу от выполненной работы, а служит дополнительным стимулом заниматься регулярно, удерживая фокус на задачах с помощью Помодоро.

## 5. Особенности
Главная особенность приложения - сочетание обычного Pomodoro-таймера с системой RPG.
За завершённые фокус-сессии пользователь получает опыт и повышает уровень. При этом приложение не должно превращаться в полноценную игру, ради которой приходится выполнять дополнительные действия.

Таймер остаётся основной функцией, а RPG-механики дополняют его.
Приложение будет работать без подключения к интернету.

## 6. Видение развития
На первом этапе планируется создать  Pomodoro-таймер с начислением опыта, системой уровней и сохранением прогресса.
В дальнейшем можно добавить достижения, новые элементы прокачки. Развитие этих механик будет зависеть от того, насколько они полезны и интересны пользователям.

При добавлении новых функций важно сохранить простоту приложения. Пользователь должен иметь возможность открыть его и начать фокус-сессию без лишних действий.
- **Без обязательного интернета.** Основные функции приложения должны быть доступны офлайн.
- **Умеренная геймификация.** Новые игровые элементы добавляются только в том случае, если они делают использование приложения интереснее, не усложняя его.
